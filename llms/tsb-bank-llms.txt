# TSB Bank

> TSB Bank plc is a British retail and commercial bank (a subsidiary of Banco Sabadell) and an FCA-authorised PSD2 account servicing payment service provider. It participates in UK Open Banking, publishing OBIE-conformant Open Data reference APIs plus FAPI-secured Account Information (AIS), Payment Initiation (PIS), and Confirmation of Funds (CBPII) services via a public developer portal. Identity is served by a Curity OAuth Toolkit OpenID Provider.

## APIs
- [TSB Open Data API](https://www.tsb.co.uk/help-and-support/open-banking/): Public, unauthenticated OBIE Open Data — ATMs, branches, personal & business current accounts, unsecured SME loans, commercial credit cards.
- [TSB OAuth Toolkit (OTK) Server](https://apis.tsb.co.uk/.well-known/openid-configuration): OpenID Connect / OAuth2 authorization server (authorize, token, userinfo, JWKS, dynamic client registration).
- [TSB Account & Transaction Information API (AIS)](https://apis.developer.tsb.co.uk/): FAPI-secured OBIE Read/Write account, balance, and transaction data (onboarding required).
- [TSB Payment Initiation API (PIS)](https://apis.developer.tsb.co.uk/): FAPI-secured OBIE Read/Write domestic and scheduled payment initiation (onboarding required).
- [TSB Confirmation of Funds API (CBPII)](https://apis.developer.tsb.co.uk/): FAPI-secured OBIE Read/Write funds-availability confirmation (onboarding required).
